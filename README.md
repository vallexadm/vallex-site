Este é um projeto Next.js (https://nextjs.org/) inicializado com o create-next-app (https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## PARA INICIAR O PROJETO

Primeiro execute o editor de desenvolvimento, neste caso utilizamos o VsCode.

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra ou acesse o link: http://localhost:3000 com seu navegador para ver o resultado. 
Você pode começar a editar a página modificando o arquivo `app/page.tsx`. A página é atualizada automaticamente conforme você edita o arquivo.

Este projeto utiliza `next/font` para otimizar e carregar automaticamente a Geist, uma nova família de fontes criada para a Vercel.

A maneira mais fácil de realizar o deploy da sua aplicação Next.js é utilizando a plataforma Vercel (https://vercel.com/), criada pelos desenvolvedores do Next.js.

Consulte a documentação sobre deploy no Next.js para obter mais detalhes em: https://nextjs.org/docs/app/getting-started/deploying.
